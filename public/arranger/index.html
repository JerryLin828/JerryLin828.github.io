    Texture

    In GarageBand: put a strings sound on each track (Library → Strings), the same ensemble on all four, or violin sounds on the top two and a cello sound on Cellos.

    Style

    In GarageBand: a bass sound on the Bass track (Library → Bass) and a kit on the Drums track (Library → Drum Kit). For a fuller band, try the lighter left hand on the Piano page.

    Using it in GarageBand
    1. Set the GarageBand project tempo to 72 bpm and the time signature to 4/4. Do this first: GarageBand keeps its own tempo.
    2. Click Save MIDI, then drag the .mid file from Finder into the empty grey area below the existing tracks. Each page saves its own part: piano, strings, or bass & drums. Drop each file at bar 1 and they line up.
    3. Each part arrives as its own track (Left hand, Right hand · Violins I, Violins II, Violas, Cellos · Bass, Drums). Pick a sound for each one in the Library. A MIDI file can't choose the instrument (see the suggestion on each page).
    4. The sustain pedal comes through on both hand tracks; the strings carry expression swells (CC11). If notes ring too long, try another patch or lower the track's sustain in the Smart Controls.
    Chart syntax
    • Asus2 E/G# F#m7 | Dadd9 separate chords with spaces, |, commas or new lines.
    • Bm7 4 or E 1 or G 1/2 sets a length in beats; otherwise the default (Beats per chord) applies.
    • N.C. or rest is silence for the default length; rest 4 rests for four beats. % repeats the previous chord.
    • [Verse] on its own line starts a section. Repeating a label with no chords under it plays that section again.
    • Verse Verse Chorus on its own line, or Structure: Intro Verse x2 Chorus, sets the order.
    • // comment is ignored.
    • Qualities: m dim aug + sus2 sus4 5 6 m6 7 maj7 M7 m7 mMaj7 m7b5 ø dim7 7sus4 add9 madd9 add11 madd11 9 maj9 m9 11 13 7b9 7#9. Slash chords: A/C#.
    • [Chorus @arp] gives a section its own pattern; C#m7@block changes one chord; a lone @pulse switches the rest of the section. Patterns: @block @block2 @roll @broken @arp @pulse (@block2 strikes each chord twice).
    • Asus2^B puts B on top of the right hand; Asus2^B4 picks the exact note.
    • Asus2_A1 sets the left hand: bass A1 plus its octave. _A1+5 adds the fifth instead, _A1- plays the single note. Tags combine: Esus4_E1+5^A@arp.
    • Strings: [Chorus ~rise ~walk] gives a section its string texture (~pad ~counter ~rise ~fall) and the cello walk; a lone ~fall switches the rest of the section. Piano and string tags can share a label: [Verse @roll ~counter].
    • Bass & drums: [Chorus !crash !busy !strong]. Moments: !crash (start), !fill, !build, !stop (end), !out (no band). Settings: !sparse !normal !busy, !soft !medium !strong, !pop !ballad !rock !rnb !soul !funk. In a line, C G !fill Am fills into Am.
    • Note names follow GarageBand: middle C is C3.
