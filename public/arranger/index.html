    In GarageBand: put a strings sound on each track (Library → Strings), the same ensemble on all four, or violin sounds on the top two and a cello sound on Cellos.

    Style
    Layers

    In GarageBand: a bass sound on the Bass track (Library → Bass) and a kit on the Drums track (Library → Drum Kit). For a fuller band, set the Piano page's left hand to “Lighter where the bass plays”.

    Using it in GarageBand
    1. Set the GarageBand project tempo to 72 bpm and the time signature to 4/4. Do this first: GarageBand keeps its own tempo.
    2. Click Save MIDI, then drag the .mid file from Finder into the empty grey area below the existing tracks. Each page saves its own part: piano, strings, or bass & drums. Drop each file at bar 1 and they line up.
    3. Each part arrives as its own track (Left hand, Right hand · Violins I, Violins II, Violas, Cellos · Bass, Drums). Pick a sound for each one in the Library. A MIDI file can't choose the instrument (see the suggestion on each page).
    4. The sustain pedal comes through on both hand tracks; the strings carry expression swells (CC11). If notes ring too long, try another patch or lower the track's sustain in the Smart Controls.
    Chart syntax
    • Asus2 E/G# F#m7 | Dadd9 separate chords with spaces, |, commas or new lines.
    • Bm7 4 or E 1 or G 1/2 sets a length in beats; otherwise the default (Beats per chord) applies.
    • Em-F#m splits one chord's time between two chords (1 beat each by default); Em-F#m 4 gives the pair 4 beats, A-B-C#m splits in three. Each part can have its own tags. With Block ×2, each part gets one block.
    • N.C. or rest is silence for the default length; rest 4 rests for four beats. % repeats the previous chord.
    • [Verse] on its own line starts a section. Repeating a label with no chords under it plays that section again.
    • Verse Verse Chorus on its own line, or Structure: Intro Verse x2 Chorus, sets the order.
    • [Verse 2 = Verse] plays Verse's chords and tags (fills, hits and all) under its own name. Tags on the copy win: [Verse 2 = Verse @arp !nohit]. A section played again by name always sounds the same; a copy is how you make it differ.
    • + builds a section one step further than what it's based on (the section it copies, or the song settings); ++ two steps. The piano moves more (Block → Block ×2 → Broken → Arpeggio, Roll → Broken) and sits higher; a held string pad becomes a counter-line and violin lines move up an octave; the band goes up a frequency (at Busy, a tambourine joins) and opens with a crash. Tags on the section win: [Chorus 2 = Chorus + @block2] keeps Block ×2, and a tagged frequency keeps the band as it is.
    • Changing one chord inside a copy (from its chord picker) first writes the copy's chords out under its label, so the original stays as it is. "Write out chords" in the section picker does the same by hand.
    • // comment is ignored.
    • Qualities: m dim aug + sus2 sus4 5 6 m6 7 maj7 M7 m7 mMaj7 m7b5 ø dim7 7sus4 add9 madd9 add11 madd11 9 maj9 m9 11 13 7b9 7#9. Slash chords: A/C#.
    • Leave an instrument out of a section: @out (piano), ~out (strings), !out / !nodrums / !nobass.
    • [Chorus @arp] gives a section its own pattern; C#m7@block changes one chord; a lone @pulse switches the rest of the section. Patterns: @block @block2 @roll @broken @arp @pulse (@block2 strikes each chord twice).
    • Left hand per section: [Chorus @light] (one note or an open fifth, for use with bass) or [Verse @full] (low octaves); otherwise the Left hand setting applies. A lone @light changes the rest of the section.
    • Asus2^B puts B on top of the right hand; Asus2^B4 picks the exact note.
    • Asus2_A1 sets the left hand: bass A1 plus its octave. _A1+5 adds the fifth instead, _A1- plays the single note. Tags combine: Esus4_E1+5^A@arp.
    • Strings: [Chorus ~rise ~walk] gives a section its string texture (~pad ~counter ~rise ~fall) and the cello walk; a lone ~fall switches the rest of the section. Piano and string tags can share a label: [Verse @roll ~counter].
    • Bass & drums: [Chorus !crash !busy !strong]. Starts: !crash, !hit (big unison accent), !hits (three strikes, then the groove), !pickup (snare pickup). Ends: !fill, !build, !stop, !endhits (strikes on the last beats). Leave out: !out, !nodrums, !nobass. Feel: !half, !four, !backbeat. Cymbal: !hats, !ride, !openhats. Layers: !clap, !tamb, !shaker (!noclap… to turn off). Settings: !sparse !normal !busy, !soft !medium !strong, !pop !ballad !rock !rnb !soul !funk. In a line, C G !fill Am fills into Am.
    • Change key with the menu or −1/+1 next to Key: the chart is rewritten in the new key (tags and pinned notes move too). To change key for one section, use Key −1/+1 in its section picker; for "last chorus up a step", give it its own label like [Chorus 2 = Chorus] and use its Key +1 (its chords are written out first).
    • Note names follow GarageBand: middle C is C3.
